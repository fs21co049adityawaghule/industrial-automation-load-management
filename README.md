# INDUSTRIAL AUTOMATION – IoT-Based Industrial Load Management System

A modern, responsive engineering project website for an **IoT-Based Industrial Load Management System**. Designed for monitoring electrical loads, automated relay switching, and integration with smart ecosystems.

---

## ⚡ Key Highlights

- **Hero & Live Demo**: Continuous autoplay demonstration video of the working hardware rig.
- **System Overview**: Detailed breakdown of industrial load management, IoT telemetry, remote control, and voice assistant integration (Alexa & Google Home).
- **Project Team**: Aditya Waghule, Smiksha Mane, Ankita Kumbharkar, Gitanjali Salunkhe.
- **Documents & Hardware Showcase**: Direct download of the verified project report (`.docx`), research paper status, and high-resolution PCB and hardware photographs with lightbox zoom.
- **Visual Gallery**: Multi-channel smart integration showcases, technical schematics, and individual test videos with HTML5 controls.
- **Contact & Enquiry**: Interactive enquiry form with field validations, file attachment dropzone, and verified academic email contact links.

---

## 🛠️ Technology Stack

- **Frontend**: React 18, Vite 6, Pure CSS3 (Responsive Grid & Flexbox)
- **Typography**: Chakra Petch & Inter
- **Media**: Local MP4 video streaming & high-resolution project captures
- **Deployment**: Zero-dependency static client-side bundle

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or pnpm

### Installation

1. Clone this repository:
   ```bash
   git clone <repo-url>
   cd <repo-folder>
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` (or the port indicated in terminal) in your browser.

4. Build for production:
   ```bash
   npm run build
   ```

5. Preview the production build:
   ```bash
   npm run preview
   ```
